# PROMPTS

## Objetivo

Este archivo contiene los prompts oficiales para trabajar con Roo Code en PlayPlatform.

Todos los prompts deben respetar la documentación ubicada en la carpeta `.ai`.

---

# 1. Analizar el proyecto

Lee toda la carpeta `.ai`.

Analiza la arquitectura del proyecto.

No modifiques ningún archivo.

Entrega:

- Resumen del proyecto.
- Arquitectura detectada.
- Riesgos encontrados.
- Oportunidades de mejora.

---

# 2. Implementar un Sprint

Lee la carpeta `.ai`.

Analiza el proyecto.

Implementa únicamente el Sprint indicado.

No agregues funcionalidades extra.

Respeta la arquitectura existente.

Al finalizar informa:

- Archivos modificados.
- Resumen de cambios.
- Riesgos encontrados.

---

# 3. Refactorizar

Analiza el código relacionado.

Reduce complejidad.

No cambies comportamiento.

No rompas compatibilidad.

Mantén la arquitectura.

---

# 4. Buscar código duplicado

Busca código repetido.

Propón una solución.

No modifiques archivos.

Espera aprobación.

---

# 5. Revisar arquitectura

Analiza:

- Dependencias.
- Acoplamiento.
- Cohesión.
- SOLID.
- Escalabilidad.

No escribas código.

---

# 6. Buscar errores

Analiza el proyecto.

Busca:

- Imports rotos.
- Dependencias circulares.
- Código muerto.
- Variables sin usar.
- Riesgos futuros.

No modifiques archivos.

---

# 7. Documentar

Genera documentación técnica de los módulos solicitados.

No cambies código.

---

# 8. Antes de programar

Siempre:

1. Leer `.ai`.
2. Comprender el objetivo.
3. Analizar impacto.
4. Esperar autorización si el cambio afecta la arquitectura.

---

# Regla principal

Nunca modificar el proyecto sin comprender primero la documentación de la carpeta `.ai`.
